# Candidate pip designs for tools/dicepreview.py --stamps.
#
#   tools/dicepreview.py --stamps tools/pipstamps.txt -o /tmp/pips.png
#
# Each stamp is an 8x8 block laid over one cell of the die's plain frame:
# '.' keeps whatever the frame already has there (face colour, bevel edge,
# corner bite), and any other letter is one of tiles.h's own pen aliases —
# B background, K pip ink, H lit edge, S shaded edge. That is exactly how
# the DIE_CELL_*_PIP macros are built, so what this draws is what shipping
# the design would draw.
#
# The rejected candidates are kept deliberately. They are the cheap part of
# an art pass to redo and the expensive part to re-learn.

# Extra pen letters beyond tiles.h's own B/K/H/S aliases.
= D PEN_DIM

# A stamp is a pip *shape*; where each one lands is this placement rule.
# 'inset 1' pulls every outer pip one pixel toward the die's centre — left
# column right, right column left, top row down, bottom row up — and leaves
# the centre pip alone. tiles.h bakes the same rule into its _PIP macros, so
# the shipped stamp below plus this inset renders exactly what ships.
~ inset 1

# --- what ships (Phase 3c refinement) ---------------------------------
#
# A drilled hole: 5x5 round body with a lit lip on the bottom-right arc,
# the same bevel trick the die body plays one scale up. Light comes from
# the top-left, so the far inner wall of a hole is what catches it.
#
# Sits at rows/cols 1-5. An odd width cannot centre on a 24px die, so the
# ink lands a pixel up-left of centre — which the lip extending down-right
# balances out.
@ drilled 5x5 (shipped)
........
..KKK...
.KKKKK..
.KKKKK..
.KKKKH..
..KHH...
........
........
